# Roof Object Detection

Der Use Case erkennt Dachobjekte in Orthofotos und ordnet geprüfte Ergebnisse Gebäuden oder Dachflächen zu. Nutzer, Ontologie, fachliche Entscheidung, Modellarchitektur und Freigabekriterien sind offen. Er demonstriert die Trennung von Source Quality, Prediction Quality und kuratiertem Ergebnis.
