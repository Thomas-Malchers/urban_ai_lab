# Datenzugriff

Data Scientists nutzen SQL, Python, Notebooks, GeoParquet, Raster- und Punktwolkenzugriff sowie Dataset Manifests. Entwickler nutzen APIs, Views, Map-/3D-Services und Inference Interfaces. Fachanwender erhalten Demonstratoren, Dashboards, Karten, Berichte und Exporte; die Öffentlichkeit nur freigegebene oder aggregierte Inhalte.

Demonstratoren greifen auf veröffentlichte Datenprodukte und definierte Schnittstellen zu, nicht direkt auf temporäre Trainings- oder Pipelineartefakte.
