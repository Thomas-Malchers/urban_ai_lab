# Urban Data Platform

Die Plattform bewahrt Originaldaten, führt domänenspezifische Ingestion und Qualitätssicherung aus und veröffentlicht verantwortete Data Products. Integration erfolgt über stabile interne Objekt-IDs und nachvollziehbare Quellreferenzen, nicht durch eine undifferenzierte Gesamttabelle.
