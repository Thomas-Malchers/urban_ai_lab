# Roadmap

Alle Termine sind offen.

1. **Documentation Foundation:** Repository, MkDocs, Navigation, Templates, ADRs, Gesamtarchitektur, CI.
2. **Architecture Baseline:** Data Platform, AI Platform, Domains, Products, Urban Data Model.
3. **Orthophoto Vertical Slice:** Collection, Roof Objects, Predictions, Building Assignment, Review, Active Learning.
4. **Additional Domains:** LiDAR, CityGML, externe Daten und Integration.
5. **Platform Decisions:** Storage, Orchestrierung, Annotation, Tracking, Registry, Inference, Monitoring, APIs, Visualisierung.
6. **Implementation Architecture:** Ist-Zustand, Deployment, Security, Betrieb, Migration und Backlog.
