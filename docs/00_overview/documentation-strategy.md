# Dokumentationsstrategie

Git und MkDocs sind die technische Quelle der Wahrheit für Architektur, Datenprodukte, Verträge, Pipelines, ADRs und Diagrammquellen. Confluence kann Vision, Roadmap, Teamorganisation, Meetings, Workshops und Onboarding bündeln und auf diese Website verlinken. Technische Dokumente werden nicht parallel kopiert.

Markdown, Mermaid, YAML und Draw.io-Quellen werden gemeinsam reviewed und versioniert. Status und Architekturzustand machen Entwurf, Zielbild und Implementierung sichtbar.
