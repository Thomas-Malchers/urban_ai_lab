# AI Platform

Die AI Platform ist eine Sammlung modularer Fähigkeiten: Data Science, Dataset/Annotation Management, Training, Experiment Tracking, Registry, Pre-/Postprocessing, Batch Inference, optional Online Inference, Monitoring, Active Learning, Review und Write-back. Ein Use Case wählt nur benötigte Komponenten.
