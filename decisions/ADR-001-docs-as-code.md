# ADR-001: Docs as Code

**Status:** Proposed

## Context
Technische Inhalte benötigen Versionierung, Review und eine lesbare Oberfläche.
## Decision
Git ist technische Quelle der Wahrheit, MkDocs die primäre Oberfläche. Confluence ist optionales Portal, keine technische Hauptablage.
## Consequences
Änderungen sind reviewbar; doppelte Pflege wird vermieden.
## Alternatives Considered
Confluence als alleinige Ablage; unversionierte Dateien.
